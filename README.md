# HyperAgent-client «Кодобольный»

## Установка и запуск клиента

Требуемая версия Python: 3.14

Установите зависимости:
```
pip install -r requirements.txt
```

Запустите клиент:
```
python client/qt_main.py
```

**Флаги запуска:**

- `--work-dir <путь>` — рабочий каталог для выполнения команд агента (по умолчанию: папка, из которой запущен клиент)
- `--data <путь>` — директория, в которой хранится JSON с настройками клиента (по умолчанию: %APPDATA%\Hyperagent)


## Сборка .exe для Windows
```
python script_to_exe.py
```

Данный скрипт генерирует .exe-файл клиента, добавляет его в PATH (hyperagent-client) и в контекстное меню (пункт "Open Hyperagent Client here"). 
Благодаря этому клиент можно будет запустить либо через консоль:
```
hyperagent-client --data .
```
либо через контекстное меню в любой папке, и тогда она станет рабочей папкой клиента по умолчанию.

## Локальная информация

Информация о клиенте сохраняется локально (IP-адрес сервера, логин, пароль, последние выбранные настройки) и подгружается при перезапуске. По умолчанию она хранится в %APPDATA%\Hyperagent. 
Поэтому, чтобы на одном устройстве запустить несколько клиентов с разными аккаунтами, необходимо запускать их с флагом --data <путь>, указывая для каждого клиента разный путь.

## Первый запуск
В первом окне необходимо указать IP-адрес сервера (пустой ввод означает localhost). Затем логин и пароль (если пользователя с таким логином еще не существует, то он будет зарегистрирован с текущим паролем).
После авторизации маршрутизатор выделит агента для пользователя, и откроется основной интерфейс работы с агентом.

## Настройки

Пользователь прямо в окне чата может выбрать модель, с которой будет работать агент.
- **Hyper** — модели, подключенные к серверной Ollama.
- **Ollama** — пользовательская Ollama (URL указывается в настройках в поле *Ollama URL*).
- **OpenRouter** — модель с openrouter.ai. Необходимо будет ввести ваш API-ключ и после этого выбрать доступные на данном ресурсе модели.
- **OpenAI** — аналогично, необходимо ввести OpenAI API key и выбрать модель.

Также в настройках можно поменять IP-адрес сервера, указать рабочую директорию и поменять тему приложения.
